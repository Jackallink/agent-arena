v0.5.1 · 双 Agent 结对开发编排器 · Local-first

两个 AI Agent，一个可审计的交付闭环

Agent Arena 把两个不同来源的 AI agent（一个写代码、一个评审）放进完全隔离的工作区， 自动协作完成 写码 → 提交 → 验证 → 决策 → 批准 的闭环； 支持 人工 / 自动双模式，有人值守或无人值守都能安全推进。

Two agents from different providers, one isolated, SHA-bound, unattended-ready loop: write → submit → validate → decide → approve, with human or auto approval modes.

解决什么问题

当两个 AI agent 结对开发，真正规模化的问题不是"能不能写码"，而是"如何可信地协作"。

✗ 没有隔离，互相污染

两个 agent 共享工作区：writer 的改动、reviewer 的检查互相干扰；评审快照随时可能被改写，审计无从谈起。

✗ 没有权威状态与审计

"下一个是谁、在等什么、怎么释放"只能靠聊天记录和人的记忆；验证/决策没有 SHA 绑定，出了事无法追溯。

✗ 无人值守就失控

批准必须人肉点击、卡住没人知道、模型面板死了任务静默停摆——"跑起来"和"安全地跑起来"是两回事。

✗ 绑定单一模型/厂商

writer 与评审耦合在同一生态，无法自由组合"最会写的"和"最会审的"两个模型。

核心优势

隔离、审计、双模式、可恢复 —— 让多 Agent 协作达到生产级可信度。

🧩

自带模型，自由组合

任意 writer（Pi / Codex / OpenCode / Agy）× 任意 gate（Cursor / OpenCode）。已在真实环境用 Pi writer + Cursor reviewer 端到端验证。

🛡️

隔离是设计出来的

每个 run 独立 Git worktree 与 tmux 会话；评审快照为 detached HEAD，任何污染都会被运行后完整性检查检出。

🔏

审计真相，不是聊天记录

SHA 绑定的验证报告与决策记录是权威；run-state.tsv 回答"下一个是谁、在等什么、何时开始、如何释放"。

🤖

人工 / 自动双模式

human 模式保留人工批准；auto 模式 + autopilot 让顺利路径无人值守完成，并对每条停滞路径报警（exit 6）。

♻️

崩溃可恢复

creation / repair intent 让中断的转移可重试；旧版本 run 只读投影、首次写入自动迁移。

🧪

质量门禁

56 节 hermetic 测试 + tmuxp / CLI 契约 / 打包检查 + 每次发布前真实 CLI 冒烟证据。

双模式：人工把关，还是放手自动

同一个状态机，两种运营方式 —— 切换由你决定，随时可改。

👤 Human 模式默认 · 有人值守

  • reviewer 的 APPROVE 后，由人执行 resolve --action approve 才算完成
  • autopilot 只观测与报警：--once 返回 6 表示"需要人"
  • 适合风险较高、需要逐单把关的仓库

🤖 Auto 模式opt-in · 无人值守

  • project.conf 设 approval_mode="auto"（或 start --mode auto）
  • autopilot 在冷却窗口后自动批准（actor=system，全程审计）
  • 面板死亡自动升级、停滞自动报警、writer 收到节流提醒
  • 适合验证脚本严格、低风险的仓库；随时 mode RUN_ID human 收回人工

快速开始

60 秒接入一个项目。

# 1. 项目接入（生成 .agent-arena/project.conf + validate.sh）
agent-arena init --repo /path/to/project

# 2. 启动 run（Pi 写 + Cursor 审）
agent-arena start RUN_ID --repo /path/to/project

# 3. writer 提交 checkpoint 后
agent-arena submit RUN_ID

# 4. 人工批准（默认 human 模式）
agent-arena resolve RUN_ID --action approve

# —— 或者无人值守（auto 模式）——
# project.conf: approval_mode="auto"
agent-arena autopilot --watch   # 常驻
agent-arena autopilot --once    # cron 单轮
