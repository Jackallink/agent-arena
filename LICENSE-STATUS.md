# License and release status

Effective 2026-08-13, the project is licensed under [MIT](LICENSE), with the
copyright notice recorded in that file. Public source publication is approved.

Release policy:

- A source repository may be published after a credential and tracked-file scan.
- A GitHub Release, package registry publication, or release artifact must wait
  for the applicable spec's Gate 4 evidence, release notes, and checksum.
- Never publish credentials, local run state, logs, session transcripts, or
  project-specific secrets.
